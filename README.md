# Пульс силы — рабочая версия для закрытого зала

Это мобильный дневник тренировок и закрытый клуб, который открывается в Telegram через бота @PulseSilyTrackerBot.

## Что уже работает

- План силовых тренировок на 16 недель и журнал остаются частью приложения.
- При входе в Telegram используется профиль Telegram — отдельный пароль и регистрация не нужны.
- Один закрытый клуб: владелец создаёт его, остальные вступают по приглашению.
- В профиле можно указать никнейм, возраст, вес, категорию и свободно написать стаж, например «2 года 4 месяца».
- Возраст, вес и категорию можно скрыть от группы. Никнейм и стаж видны участникам клуба.
- Можно искать участников по никнейму, отправлять и принимать заявки в друзья.
- Есть общая лента, публикации с текстом, фотографиями и видео, лайки и комментарии.
- Фото и видео хранятся в закрытом хранилище. Поддерживаются JPG, PNG, WebP, HEIC, MP4, MOV и WebM до 25 МБ.
- В разделе ленты есть рейтинг регулярности: число сохранённых тренировок за последние 30 дней.
- Тренировки и программа синхронизируются между устройствами после входа в Telegram.
- В настройках профиля можно выбрать одну из четырёх цветовых тем.

Дневник, открытый в обычном браузере, продолжает хранить данные на этом устройстве. Чтобы перенести старую историю в Telegram, открой дневник в Telegram и выбери **Дневник → Восстановить копию**.

## Настройка сервера Supabase

Для общей регистрации, друзей и ленты нужен сервер. Сам сайт остаётся на GitHub Pages. Серверные функции и база работают на Supabase. Для небольшого клуба можно начать с бесплатного тарифа; на нём есть ограничения по хранилищу и трафику, а неактивный проект могут приостановить. Текущие условия смотри на [странице тарифов Supabase](https://supabase.com/pricing).

### 1. Создай проект

Зарегистрируйся на [supabase.com](https://supabase.com), создай проект и сохрани его пароль в надёжном месте. Дождись, пока проект закончит запуск.

### 2. Создай таблицы и закрытое хранилище

1. В панели проекта открой **SQL Editor**.
2. Выбери **New query**.
3. Открой файл supabase/migrations/202610250001_gym_club.sql в Cursor и скопируй всё его содержимое.
4. Вставь его в SQL Editor и нажми **Run**.

Скрипт создаёт таблицы клуба и приватное хранилище медиа.

### 3. Добавь серверную функцию

У функции есть два способа установки.

**Через Supabase Dashboard:**

1. Открой **Edge Functions → Deploy a new function → Via Editor**.
2. Назови функцию club-api.
3. Замени текст в редакторе всем содержимым файла supabase/functions/club-api/index.ts.
4. Нажми **Deploy function**.
5. В настройках этой функции выключи **Verify JWT**. Функция сама проверяет подписанные данные входа от Telegram. Если одновременно оставить встроенную проверку JWT, Telegram Mini App не сможет войти.

У редактора Dashboard нет истории версий. Исходник всё равно останется у тебя в папке и на GitHub.

**Через Cursor Terminal:** если Supabase CLI уже установлен, из корневой папки проекта выполни команды по очереди:

    npx supabase login
    npx supabase link --project-ref ТВОЙ_PROJECT_REF
    npx supabase functions deploy club-api --no-verify-jwt

CLI возьмёт имя функции и настройку verify_jwt = false из supabase/config.toml. Для установки CLI и других способов смотри [официальную инструкцию Supabase](https://supabase.com/docs/guides/local-development).

### 4. Задай секреты функции

В панели Supabase найди настройки секретов **Edge Function Secrets** и добавь:

- TELEGRAM_BOT_TOKEN — токен от BotFather. Это секрет, его нельзя класть в GitHub или config.js.
- OWNER_BOOTSTRAP_CODE — придумай длинный код владельца клуба. Он понадобится только для создания клуба.
- APP_ORIGIN — https://andrejcarin932.github.io

Supabase сам передаёт функции адрес проекта и закрытый серверный ключ. Не копируй серверный ключ в сайт и никому его не отправляй. Инструкция Supabase по [секретам функций](https://supabase.com/docs/guides/functions/secrets).

### 5. Заполни публичные настройки сайта

Открой config.js и замени три примера:

- YOUR_PROJECT_REF — идентификатор проекта Supabase. Это часть адреса проекта перед .supabase.co.
- YOUR_SUPABASE_PUBLISHABLE_KEY — публичный ключ из **Settings → API Keys → Publishable key**.
- В functionUrl укажи адрес функции: https://ТВОЙ_PROJECT_REF.supabase.co/functions/v1/club-api.

Публичный ключ предназначен для браузера. **Не вставляй сюда Secret key или Service role key.**

### 6. Обнови GitHub Pages

1. Распакуй архив с приложением на компьютере.
2. Открой существующий репозиторий andrejcarin932/gym-tracker.
3. Загрузи содержимое распакованной папки в корень репозитория, заменив старые index.html, app.js, style.css и service-worker.js.
4. Убедись, что вместе с ними появились config.js и папка supabase с миграцией и функцией.
5. Сохрани изменения. GitHub Pages продолжит использовать тот же адрес: https://andrejcarin932.github.io/gym-tracker/.

Загружай распакованные файлы, а не сам ZIP-архив. Не добавляй токен BotFather, секретный ключ Supabase или код владельца в репозиторий.

### 7. Открой клуб в Telegram

Открой чат с @PulseSilyTrackerBot и запусти приложение кнопкой меню бота. Если кнопки ещё нет, настрой её через BotFather в **Bot Settings → Menu Button** и укажи адрес GitHub Pages выше.

При первом входе владелец вводит код OWNER_BOOTSTRAP_CODE и создаёт клуб. Приложение выдаст код приглашения: скопируй его и отправь знакомым лично. Если код потерян на устройстве владельца, кнопка приглашения выпустит новый код; предыдущий сразу перестанет работать. Остальные пользователи открывают приложение из того же бота и вводят приглашение.

Обычное открытие GitHub Pages в браузере позволяет пользоваться локальным дневником, но общая лента, клуб и профили работают при входе через Telegram Mini App. Telegram передаёт данные входа, а сервер проверяет их подпись — эти данные нельзя подтверждать только в браузере. Подробнее — в [документации Telegram Mini Apps](https://core.telegram.org/bots/webapps).

## Важно про бесплатный тариф и видео

Тариф Supabase Free сейчас бесплатный, но имеет ограничения, включая 1 ГБ файлового хранилища и 5 ГБ исходящего трафика; неактивный проект может быть приостановлен через неделю. Для компании друзей этого достаточно, чтобы начать, но видео быстрее расходуют хранилище и трафик. Тарифы могут меняться — проверь актуальные цифры перед использованием: [Supabase Pricing](https://supabase.com/pricing).

Пока рейтинг сравнивает только регулярность — количество записанных тренировок за 30 дней. Он не сравнивает килограммы, вес тела или категории, чтобы не раскрывать личные данные и не выдавать это за спортивный рейтинг.
